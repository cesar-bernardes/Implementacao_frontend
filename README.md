# GD Tech — Frontend

Aplicação web da plataforma de gestão de implementações, construída com Next.js e TypeScript.

## Execução

```bash
pnpm install
pnpm dev
```

O sistema ficará disponível em `http://localhost:3000`.

## Comandos

- `pnpm dev`: desenvolvimento.
- `pnpm build`: compilação de produção.
- `pnpm lint`: análise do código.
- `pnpm typecheck`: validação do TypeScript.

As decisões de autenticação, autorização e isolamento por empresa pertencem ao Backend.
